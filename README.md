## 📖 Description
This project is developed as part of **Task 2 of the CODTECH Internship**.  
The project focuses on building an online learning platform that supports video-based lessons, quizzes for self-assessment, and basic progress tracking, providing a student-friendly and seamless learning experience.

## 🎯 Objective
- To develop an online learning platform with a clean and student-friendly UI
- To support video lessons using media streaming
- To implement quizzes for learning evaluation
- To track user progress through the platform
- To understand basic user authentication and data storage concepts

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage / Database (for user data and progress tracking)
- Media Streaming (HTML5 Video)

## ⚙️ Features
- User authentication (login and registration)
- Video lessons with smooth playback
- Interactive quizzes for each lesson
- Progress tracking for completed lessons
- Responsive and student-friendly user interface
- Organized course and lesson structure

## 🚀 How to Run the Project
1. Download or clone the repository
2. Open the `index.html` file in a web browser
3. Register or login as a user
4. Access video lessons, attempt quizzes, and track progress
